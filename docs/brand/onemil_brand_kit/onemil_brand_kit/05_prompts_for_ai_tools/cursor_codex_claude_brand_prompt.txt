OneMil is a premium competition app for CZ/SK users. The brand must feel modern, trustworthy, luxurious, clean and energetic. It must never look like casino, gambling, betting, lottery or cheap “get rich quick” design.

Final public visual direction: LIGHT premium OneMil.
Typography: Poppins for headings, Inter for body/UI text.
Primary public canvas: white #FFFFFF, warm cream #FAFAF9, cloud #F7F8FB.
Text: dark ink #111827, secondary #4B5563.
Main accent: Energy Orange #FF8A00. Approved UI orange #F97316 may be used where it matches existing web UI. Warm Amber #FFB547 is a subtle highlight.
Do not use black, deep navy or graphite as a full-page/full-card default background for new public graphics.

Use only the original approved OneMil and MioCoin logos/icons already stored in the project. Never invent, redraw, reinterpret or recolor a new logo or symbol. If the original logo cannot be placed accurately, leave the proposal without a logo and add the original asset later.

Do not use casino, hazard, betting, jackpot, chips, roulette, cards or slot-machine aesthetics.
Do not change business logic, routes, database, payments, wallet, contests, tickets, winners or Partner Offers unless explicitly requested.
When applying this manual, only adjust visual styling, typography, colors, spacing, logo usage and brand consistency.
