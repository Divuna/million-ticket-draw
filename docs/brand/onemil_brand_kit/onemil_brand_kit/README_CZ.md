# OneMil Brand Kit

Praktický balík pro použití finálního vizuálního směru OneMil v Codexu, Cursoru, Lovable i Claude Code.

## Obsah
- `01_brand_manual/` — textový PDF a Markdown brand manual.
- `02_logos/source/` — zdrojové JPG varianty loga.
- `02_logos/png/` — PNG exporty loga a orientační transparentní verze.
- `03_icons/favicon_app/` — favicony a app ikony v běžných velikostech.
- `04_design_tokens/` — barvy, fonty, CSS a Tailwind tokeny.
- `05_prompts_for_ai_tools/` — připravené prompty pro Codex/Cursor/Claude/Lovable.
- `06_reference_images/` — grafické reference brand manualu a UI stylu.
- `07_web_snippets/` — manifest pro web/app ikony.

## Důležité
Transparentní PNG jsou vytvořené z rastrového loga na tmavém pozadí. Pro finální produkční nasazení je ideální nechat logo převést do čistého SVG/AI/Figma vektoru. SVG v balíku je pouze orientační placeholder, ne přesná vektorová kopie loga.

Fonty se neposílají jako soubory. Používej Google Fonts import pro Poppins a Inter.
