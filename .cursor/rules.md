# OneMil – Working rules (Cursor)

## State files (source of truth)

Before doing any task, always read:

- `onemil_state.md`
- `onemil_history.md`

Treat `onemil_state.md` as the single source of truth for:

- current system state
- known bugs
- next steps

Completely ignore `state.md` (do not use it).

## Updating state/history files

When the user provides updated content for:

- `onemil_state.md`
- `onemil_history.md`

Always:

- replace the entire file
- do not merge
- do not summarize
- do not modify formatting
